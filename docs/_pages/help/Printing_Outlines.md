You can print Outlines using the File menu on macOS and by using the context
menu in the Documents view on all platforms.

## Print Doc

This is for when you are using Zavala as something of a structured word
processor with headings and paragraphs. See Alternate Usage in
[The Notes Field](The_Notes_Field.md) to see how to do this.

## Print List

This is the most commonly used print format. It is the most accurate
representation of your Outline and includes everything in the Outline.

## Print Screen

This is just like Print List except it will hide Outline elements based how
things are being currently viewed on the screen. For example if you have
Completed or Notes filtered, they won’t show up in the printout. It also won’t
show the children of a Row if that Row is collapsed on the screen.

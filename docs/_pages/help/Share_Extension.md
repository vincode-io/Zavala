## What is it?

A Share Extension lets an application, like Zavala, contribute functionality to
other applications, like Safari or Chrome. When you click the Share button in
Safari or other application, it will try to send the current web page URL to
the application that you select.

## What is it good for?

This function is sometimes called a Web Clipper and is good for Personal
Knowledge Management (PKM). See the [Glossary](Glossary.md) for more on these
terms.

Let’s say we are collecting recipes. If you find a recipe on the web that you
want to keep and reference later, you can use the Share Extension to pass the
recipe to Zavala. Zavala will then download the recipe and do its best to
convert that into an outline.

You can then edit the recipe and get rid of the story at the beginning of the
recipe if you wish. You can reformat the recipe and highlight sections of text
within it. You can even [link](Linking.md) to it from another outline, for
example, a list of favorite cookie recipes.

## How good does it work?

That depends on how well the web page is structured. For more detail read
[Importing Outlines](Importing_Outlines.md) / Supported File Types / HTML.
